# Fonts

Self-hosted so the concept page makes no third-party requests. Latin subsets, as served by Google Fonts.

| File | Family | Licence |
|---|---|---|
| `bricolage-grotesque-latin.woff2` | Bricolage Grotesque (variable: weight, optical size) | SIL Open Font License 1.1, `OFL-bricolage-grotesque.txt` |
| `ibm-plex-sans-latin.woff2` | IBM Plex Sans (variable weight) | SIL Open Font License 1.1, `OFL-ibm-plex.txt` |
| `ibm-plex-mono-400-latin.woff2`, `ibm-plex-mono-500-latin.woff2` | IBM Plex Mono 400 and 500 | SIL Open Font License 1.1, `OFL-ibm-plex.txt` |

The kit does not use these files. Its PNG renderer needs complete TrueType faces, vendored separately in `kit/atelier_kit/fonts/` by `scripts/vendor-kit-fonts.py`.
